# Chapter 10. Red Hat Offline Knowledge Portal

The Red Hat Offline Knowledge Portal (RHOKP) is a lightweight, secure, offline version of the online Red Hat Customer Portal and Knowledgebase that you can use offline and at the Edge.

RHOKP is available with your Red Hat Satellite subscription. You can install RHOKP to access Red Hat documentation and search the Red Hat Knowledgebase offline in environments with limited or no internet connectivity.

Satellite web UI includes links to related documentation sources on selected pages. If a custom RHOKP instance is available in your environment, you can configure Satellite web UI to point to your RHOKP documentation source rather than the default online Red Hat documentation source at `docs.redhat.com`.
